## 實作與預覽

- `src/config/campaign.ts` 的 `pricing` 集中管理方案及來源，`status` 預設為 `draft`。
- 預設建置不顯示價格或連到不存在的費用區塊。只有 `XK_PRICING_PREVIEW=true` 的本機建置會顯示草案，首屏及方案區皆標示提案性質。
- 核定後才將 `status` 改為 `published`，完成對應文案、測試與 PR；不以推送草案或未核定條件代替正式刊登。
- 首屏顯示建置起價與比較入口；三張卡片位於首屏後方。各方案入口只前往原有需求工具，保留草稿，不默默代選方案或附加價格。
- `src/components/pricing-section.tsx` 為 Server Component；沒有新增付款、收件或追蹤操作。

```bash
XK_PRICING_PREVIEW=true NEXT_PUBLIC_BASE_PATH="" npm run build:pages
NEXT_PUBLIC_BASE_PATH="" npm run preview:pages -- --port 3010
```

`http://127.0.0.1:3010/` 為 Cloud 電腦內的測試位址；跨裝置開啟需使用環境的 HTTP Preview 或 SSH forwarding，不將此位址當成公開網址。
